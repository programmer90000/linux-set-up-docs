# Set up individual apps

## Brave

Go to Settings

- Select `Profile name and icon`
    - Set `Profile name` to `Personal`
    - Set `Theme Colour` to `Grey default colour`
    - Set `Avatar` to `Avatar Edgy Rewards`
    - Set Brave to default browser
    - Set `New Tab Page Shows` to `Dashboard`

- Select `Customise New Tab page`
    - Set `Show background images` to on
    - Set `Show sponsored images` to on
    - Select `Brave backgrounds`

- Select `Brave Stats`
    - Set `Show Brave Stats` to on

- Select `Top Sites`
    - Select `Frequently Visited`

- Select `Brave News`
    - Switch it off

- Select `Clock`
    - Switch it on
    - Select `24-hour clock`

- Select `Cards`
    - Switch it off

- Select `Search`
    - Enable `Show search widget on the new tab page`
    - Enable `Brave` and `Google` search engines

Go back to the Settings page

- Select `Apperance`
    - Set `Brave Colours` to `Dark`
    - Select `Use Classic`
    - Enable `Show tab groups in bookmarks`
    - Disable `Automatically pin new tab groups created on any device to the bookmarks`
    - Disable `Use system title bar and borders`
    - Disable `Show Home button`
    - Enable `Show bookmarks button`
    - Set `Show bookmarks bar` to on
    - Set `Show Brave News button` to off
    - Set `Show Leo AI button` to on
    - Set `Show Brave Rewards button` to on
    - Set `Show Brave Wallet button` to off
    - Set `Show sidebar button` to on
    - Set `Show autocomplete suggestions in address bar` to on
    - Enable `Top Suggestions`
    - Disable: `Browsing History`, `Bookmarks `, `Quick commands` and `Leo AI assistant`
    - Enable `Use wide address bar`
    - Enable `Always show full URLs`
    - Disable `Use vertical tabs`
    - Disable `Show tab search button`
    - Disable `Disable mute function in tab speaker icons`
    - Set `Tab hover mode` to `Tooltip`
    - Set `Show memory usage on tab hover preview card` to on
    - Set `Inactive tabs appearance` to off
    - Set `Show Sidebar` to `Never`

- Select `Content`
    - Set `Font Size` to `Medium`
    - Set `Page Zoom` to `100%`
    - Set `Cycle through the most recently used tabs with Ctrl-Tab` to off
    - Set `Show Wayback Machine prompt on 404 pages` to on
    - Set `Speedreader` to off

- Select `Shields`
    - Set `Show the number of blocked items on the Shields icon` to on
    - Set `Trackers & ads blocking` to `Standard`
    - Set `Upgrade connections to HTTPS` to `Standard`
    - Set `Block scripts` to on
    - Set `Block fingerprinting` to on
    - Set `Block cookies` to `Block third-party cookies`
    - Set `Forget me when I close this site` to off
    - Set `Store contact information for future broken site reports` to off
    - Set `Allow Facebook logins and embedded posts` to on
    - Set `Allow X (previously Twitter) embedded tweets` to on
    - Set `Allow LinkedIn embedded posts` to on

- Select `Privacy and Security`
    - Select `Security`
        - Set `Safe Browsing` to `Standard protection`
        - Enable `Use secure DNS`
