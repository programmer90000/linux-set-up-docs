# System Settings

## Apperance

### Global Theme

Set it to `Breeze Dark`

Apply the changes to both `Apperance Settings` and `Desktop and window layout`

### Application Style

Set it to `Oxygen`

### Plasma Style

Set it to `Oxygen`

### Colours

Set it to `Breeze Dark`

### Window Decorations
Set it to `Plastik`


### Fonts

- Set `General` to `Noto Sans 10pt`
- Set `Fixed Width` to `Hack 10pt`
- Set `Small` to `Noto Sans 8pt`
- Set `Toolbar` to `Noto Sans 10pt`
- Set `Menu` to `Noto Sans 10pt`
- Set `Windows Title` to `Noto Sans 10pt`
- Enable `Anti-Aliasing`
- Disable `Exclude range from anti-aliasing`
- Set `Sub-pixel rendering` to `None`
- Set `Hinting` to `None`
- Disable `Force font DPI`

### Icons

Set it to `Breeze Dark`

### Cursors

Set it to `Adwaita`

### Splash Screen

Set it to `None`

## Workspace Behavior

### General Behavior

Enable `Dsplay informational tooltips on mouse hover`

Enable `Display visual feedback for status changes`

Set `Animation speed` to the middle

Set `Clicking files or folders` to `Selects them`

Set `Clicking in scrollbar track` to `Scrolls to the clicked location`

Disable `Middle Click` `Paste selected text`

Set `Touch Mode` to `Never enabled`

### Desktop Effects

Enable: `Snap Helper`, `Background Contrast`, `Blur`, `Screen Edge`, `Desktop Grid`, `Overview`, `Present Windows`, `Tiling Editor`

### Screen Edges

Disable all screen edges

Disable `Maximise` `Windows dragged to top edge`

Disbale `Tile` `Windows dragged to left or right edge`

Disable `Behaviour` `Remain active when windows are full-screen`

Set `Trigger quarter tiling in` to `Outer 25%`

Set `Switch desktop on edge` to `Disabled`

Set `Activation delay` to `150ms`

Set `Reactivation delay` `350ms`

### Touchscreen Gestures

Disable all touchscreen gestures

### Screen Locking

Enable `Lock screen automatially` and set it to `5 minutes`

Enable `After waking from sleep`

Set `Allow unlocking without password for` to `0 seconds`

Set `Keyboard shortcut` to `Meta+L`

### Virtual Desktops

Set a single desktop: `Desktop 1`

Disable `Navigation wraps around`

Enable `Show animation when switching` and set it to `Slide`. Set the `Gap between desktops` `Horizontal` to `45` and `Vertical` to `20`. Enable `Slide desktop background`

### Recent Files

Set `Keep history` to `For 1 month`

Set `Remember opened documents` to `For all applications`
